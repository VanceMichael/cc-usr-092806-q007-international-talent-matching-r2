# 协同事务平台

协同事务平台为需要多机构参与的业务提供统一的机构、授权、案件、证据、审批、资源预约、资金分录、消息归并、通知、定时任务和历史回放能力。项目只使用 Python 标准库与 SQLite，适合在单个 Linux 应用容器内运行。

## 可追溯招聘流程

`recruiting.py` 在平台已有能力之上实现国际人才招聘编排，解决“不同招聘人员引用不同岗位版本、薪酬承诺被悄悄覆盖”的问题：

- **版本冻结**：岗位（技能、语言、签证/工作许可、薪酬预算）逐版本留存；每次推荐和面试安排都冻结当时的岗位版本、要求摘要、证件版本和候选人授权版本，后续改版不回溯影响已冻结环节。
- **承诺不可覆盖**：录用承诺一经发出只能由候选人确认、由企业留下撤回记录，或通过候选人接受的补充协议衔接；原条款始终可追溯。
- **事件只终止未完成环节**：候选人撤回授权、证件到期、岗位关闭或预算变化只取消尚未完成的推荐/面试/待审批例外，已发出的承诺原样保留。
- **资格例外分离审批**：企业可维护本方岗位，但资格例外必须由非用人企业的人才服务中心审批，申请人不能自批。
- **联系方式最小开放**：候选人联系方式只对授权 audience 内的有效人员开放，授权撤回或过期后自动掩码。
- **简历回执幂等与人工核验**：同一份简历（同标识或同摘要）重复回执保留原进度；标识相同而资格材料不同进入人工核验队列，不覆盖任何进度。
- **重启不丢待办**：证件到期、面试协调提醒、承诺确认期限全部写入持久化任务队列，worker 崩溃后租约过期自动重新领取。
- **可追溯解释**：`explain-referral` 可回答候选人为何被推荐、当时满足哪一版要求、每条例外由谁批准、下一步由谁处理。

## 目录

- `src/civicflow/`：领域服务、SQLite 持久化、权限和命令行入口。
- `tests/`：核心流程、边界条件和异常路径测试。
- `examples/`：本地演示输入。

## 配置

通过 `CIVICFLOW_DB` 指定 SQLite 文件路径；不设置时命令行使用当前目录下的 `civicflow.sqlite3`。所有时间使用带时区的 ISO 8601 字符串。

## 测试

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

## 编译或构建

```bash
PYTHONPATH=src python3 -m compileall -q src
```

## 使用

初始化数据库并运行离线演示：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 demo
```

查看当前案件：

```bash
PYTHONPATH=src python3 -m civicflow.cli --db /tmp/civicflow-demo.sqlite3 list-cases
```
